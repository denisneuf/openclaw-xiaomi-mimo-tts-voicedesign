⚙️ Cómo funciona

📎 1. El comando

/vd dialogue default-test::The storm howled... || pirate-captain::A storm? I've sailed... || ...

🔧 2. Parseo interno

El plugin divide el texto del comando con dos reglas simples:

1. fullText.split("||") → ["default-test:: The storm...", " pirate-captain:: A storm?...", ...] 2. Cada parte: indexOf("::") → separa persona del texto

🌐 3. Fetch a MiMo por segmento

Para cada segmento: 1. Busca personas[seg.persona].providers.xiaomi-voicedesign.style en openclaw.json 2. Hace fetch() a api.xiaomimimo.com/v1/chat/completions 3. Payload: { messages: [ { role: "user", content: "<style>" }, { role: "assistant", content: "<texto>" } ], audio: { format: "mp3", optimize_text_preview: <por segmento> } } optimize_text_preview varía según la persona: ├─ 01-narrador: false (global provider) ├─ 02-captain-enters: false (persona pirate-captain) ├─ 03-barman: false (persona russian-heavy) ├─ 04-mysterious: false (persona female-soft) ├─ 05-sage: true (persona lord-of-the-rings, override explícito) └─ 06-captain-final: false (persona pirate-captain) 4. Recibe response.json().choices[0].message.audio.data (base64) 5. Decodifica: Buffer.from(audioData, "base64")

🧩 4. Concatenación de MP3

Cada segmento devuelve un MP3 independiente. Para unirlos sin cortes:

1. El primer buffer se incluye tal cual. 2. Para cada buffer siguiente: - Si empieza con "ID3" (header ID3v2), se salta: const size = (b[6]<<21) | (b[7]<<14) | (b[8]<<7) | b[9]; b = b.subarray(10 + size); 3. Buffer.concat(cleanBuffers) → MP3 sin metadatos duplicados → audio seamless.

🔄 6. Flujo completo (del comando al audio)

1
Usuario escribe: /vd dialogue default-test:: The storm... || pirate-captain:: A storm?... || ...
2
Plugin parsea: split por || → cada segmento: indexOf("::") separa persona y texto
3
Plugin lee config: lee openclaw.json para sacar el style de cada persona
4
Fetch ×6: llama a la API de MiMo una vez por segmento, con el style de la persona correspondiente. Cada llamada devuelve un buffer MP3 (base64)
5
Concatena: limpia headers ID3 de los segmentos 2-6, luego Buffer.concat() todos los buffers limpios
6
Escribe: guarda en /tmp/voicedesign-dialogue-<timestamp>.mp3
7
Responde: el plugin devuelve la ruta del archivo en el chat
8
Canvas: se copia manualmente a ~/.openclaw/canvas/MiMo-V2.5-TTS-VoiceDesign/ y se enlaza en este HTML
