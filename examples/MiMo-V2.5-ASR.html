⚠️ Limitaciones

Idiomas: Solo chino (zh) e inglés (en). Español, francés, japonés, etc. no funcionan.

iMessage transient: Los audios de iMessage expiran en 2 min si no se pulsa "Keep" — el Mac mini puede no recibirlos.

Rate limit: La API de MiMo tiene rate limiting agresivo (~3 llamadas seguidas → 429).

📖 API Reference: https://mimo.mi.com/models/mimo-v2.5-asr
